# Resourcify India client demo

Static landing page with searchable fictional openings and a browser-local CRM for employees, firms, openings and enquiries. All seeded records are fictional. No requests are sent, there is no authentication, and records are not shared between browsers.

Serve `dist` with a static HTTP server. The font has a system fallback if Google Fonts is unavailable. Before production, add authenticated staff access, a shared database, access controls, consent and retention workflows, and verified business details.
